# Hello OSS Project

## Giới thiệu
Đây là dự án C đơn giản in ra dòng chữ “Hello Open Source!”.

## Mục tiêu
- Làm quen với cấu trúc một dự án mã nguồn mở.
- Thực hành biên dịch và chạy chương trình C.
- Tìm hiểu cách viết tài liệu và giấy phép cho dự án.

## Yêu cầu
- Đã cài GCC.

## Build và chạy chương trình
Mở terminal tại thư mục dự án, sau đó chạy:

```bash
gcc hello.c -o hello
./hello

## Thực hành GitHub Codespaces

Dự án được mở, chỉnh sửa và chạy thử trong GitHub Codespaces.
Môi trường cloud giúp contributor làm việc mà không cần cài đặt toàn bộ công cụ trên máy cá nhân.
